# Contributing to GravLensAI

Thanks for helping improve GravLensAI. Keep contributions focused, test-backed, and consistent with the existing code style.

## Quick Workflow

1. Fork the repository and clone your fork.
2. Create a feature branch from `main`.
3. Install dependencies with `pip install -e ".[dev]"`.
4. Make a focused change.
5. Run `ruff`, `mypy`, and `pytest` before opening a PR.

## Code Style

- Use type hints for public functions.
- Keep docstrings short and factual.
- Prefer explicit names over abbreviations.
- Avoid broad refactors in the same PR as a bug fix.

## Testing

- Add tests for new behavior.
- Keep tests deterministic where possible.
- Run the relevant subset of tests locally before pushing.

## Pull Requests

- Describe what changed and why.
- Link any related issue.
- Mention any assumptions or tradeoffs.
- Include screenshots or plots if you changed visual output.
